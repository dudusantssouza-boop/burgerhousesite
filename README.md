# Burgerhousesite

Crie um site de cardápio digital moderno, bonito e responsivo para uma hamburgueria fictícia chamada Burger House.

O site deve conter:

Design profissional, com cores preto, amarelo e branco.

Banner principal com foto de hambúrgueres.

Categorias: hambúrgueres, combos, acompanhamentos e bebidas.

Cards com fotos, nomes, descrições e preços fictícios.

Botão "Pedir pelo WhatsApp" em cada produto.

Seção com endereço, horário de funcionamento e localização.

Layout otimizado para celulares.

Requisitos:

Não utilizar banco de dados.

Não criar login ou cadastro.

Não armazenar dados pessoais.

Não implementar pagamentos.

Os botões do WhatsApp devem abrir uma conversa com um número de demonstração claramente identificado, sem simular um pedido enviado.

Criar uma área de fácil edição dos produtos no próprio código.

Utilize produtos e informações fictícios e deixe o projeto pronto para ser publicado como uma demonstração de portfólio.
